# Lab

Side projects that aren't hand-tracked, living next to the toys. Each folder is its own
project with its own README. They're served by the same static site, so `python serve.py`
and open `/lab/<project>/`.

## Sims
- **antfarm/**: a leafcutter ant farm at real scale and real time, solo or two colonies at war.
  Imported with its full history from the old standalone repo.

## Courses
- **courses/algorithms/**: every algorithm from the U of T CS theory sequence and CLRS, up to
  P vs NP, as sandboxes you can poke. Built overnight by the night runner, one module per ticket.
- **courses/llm/** (not started): build a small language model from scratch to learn the basics.
- **courses/security/** (not started): advanced cybersecurity, self-study through CTF puzzles.
- **courses/quantum/** (not started): a visual course on how quantum computers work.
